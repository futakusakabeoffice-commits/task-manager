# Visual Design System (DESIGN.md)

本ファイルは、AIエージェントがUIコード（HTML, CSS, React, など）を生成する際に参照するデザイン仕様書です。UIを構築する際は、必ずこのルールに従ってください。

※本仕様は、提供いただいた参考サイト（和食・焼肉系飲食店サイト）のスクリーンショットを分析して抽出したものです。カラーコードは画像からの推定値のため、実装時に微調整してください。

## 1. トーン＆マナー
* **ブランドイメージ:** 和モダン、伝統と上質さ、温かみ、職人・食材へのこだわり
* **コアバリュー:** 「美味しそう」と感じさせる食欲訴求と、老舗・専門店らしい信頼感の両立
* **世界観:** 和紙・古紙のようなテクスチャ背景、山並みのグラフィックモチーフ、縦書きの和文タイポグラフィを効果的に使用し、単なる「飲食店サイト」ではなく「旅先・目的地」のような特別感を演出する

## 2. カラーパレット (Colors)
指定された役割（トークン）に応じて、以下のカラーコードを厳密に使用してください。
* **Primary（ブランドカラー／朱色）:** `#E2592C` (例: 洋菓子ではなく食欲をそそる朱色・テラコッタオレンジ。CTAボタン、タグ、見出しアクセントに使用)
* **Primary Dark（ホバー・濃淡用）:** `#C74A22`
* **Secondary（背景アクセント／土色）:** `#D98C4A` (山並みイラストのグラデーション中間色)
* **Background（メイン背景／生成り）:** `#F1E4CE` (例: 和紙・古紙のようなオフベージュ。うっすらとしたテクスチャを重ねる)
* **Background Light（セクション背景）:** `#F8F0E1`
* **Surface（カード背景）:** `#FFFFFF` または `#FDFBF6` (メニューカードなど、写真を引き立てる面)
* **Text Main（本文・見出しテキスト）:** `#231F1B` (黒に近いチャコールブラウン)
* **Text Muted（薄いテキスト／日付・キャプション）:** `#9C9187`
* **Border（境界線・区切り線）:** `#E3D5BC`
* **Accent Tag（特長ラベル背景）:** `#E2592C`（白文字との組み合わせで使用）

## 3. タイポグラフィ (Typography)
* **フォントファミリー（日本語・見出し）:** `"Shippori Mincho", "Noto Serif JP", "Hiragino Mincho ProN", serif`（明朝体で、和の上質さ・職人らしさを表現）
* **フォントファミリー（日本語・本文）:** `"Noto Serif JP", "Hiragino Mincho ProN", serif`（見出しと統一し、上品な世界観を保つ）
* **フォントファミリー（英数字・ロゴ／装飾文字）:** `"Cormorant Garamond", "EB Garamond", serif`（"YORO" のような大型欧文ロゴ・縦組みラベルに使用する、細身でエレガントなセリフ体）
* **ベースフォントサイズ:** `16px` (1rem)
* **見出し 1 (h1):** `2.75rem` (44px), `line-height: 1.4`, 通常〜太字、行間広め（縦書き・大型ステートメント見出し向け）
* **見出し 2 (h2):** `1.75rem` (28px), `line-height: 1.5`, 通常
* **本文 (p):** `1rem` (16px), `line-height: 1.9`（和文は行間を広めに取り、可読性を担保）
* **ナビゲーション・ラベル文字:** `0.875rem` (14px), 文字間隔（letter-spacing）を `0.1em` 程度広めに取り、縦書き時の可読性を確保
* **縦書き（writing-mode: vertical-rl）:** ナビゲーションメニュー、サイドラベル（英字ロゴなど）に積極的に使用可

## 4. スペースとレイアウト (Spacing)
余白や配置は、以下の8pxグリッドシステム（ベースは4px）を基準に設定してください。全体的にゆったりとした余白を取り、高級感・非日常感を演出します。
* `px` (Padding/Margin): `4px`
* `spacing-1` (最小の余白): `8px`
* `spacing-2` (標準的な余白): `16px`
* `spacing-3` (セクション内要素間): `32px`
* `spacing-4` (セクション間の余白): `80px`
* `spacing-5` (ヒーローセクションなど大余白): `120px`
* **レイアウト方式:** CSS Grid を優先。写真を中心に据えた非対称レイアウト（中央に円形トリミング写真＋左右に縦書きテキスト）を基本構成とする。
* **サイドナビゲーション:** 画面右端に固定の縦書きナビゲーション（幅 80px程度）を配置し、最右端にCTAボタン（予約タブ）を固定表示する構成を標準とする。

## 5. コンポーネントスタイル (Components)
* **ボタン（プライマリCTA／予約タブ）:**
  * 形状: 画面右端に固定される縦長タブ形状（幅 96px、高さ 180px程度）
  * 背景色: `Primary` (`#E2592C`)
  * 文字色: `#FFFFFF`、縦書き
  * 角丸 (border-radius): `0`（画面端に密着するため角丸なし、または内側のみ角丸）
  * アイコン: 下部に円形の白背景アイコン（カトラリーなど）を配置
  * ホバー時のエフェクト: 背景色を `Primary Dark` に変化
* **ボタン（通常）:**
  * 角丸 (border-radius): `24px`（ピル型）
  * パディング: 縦 `12px`, 横 `24px`
  * シャドウ: `none`
  * ホバー時のエフェクト: 背景色を少し暗くし、`transform: translateY(-2px)` を適用
* **カード（メニュー・商品カード）:**
  * 背景: `Surface` (`#FFFFFF` / `#FDFBF6`)
  * 画像: カード上部いっぱいに配置、角丸 `12px`（上2角のみ、または全体）
  * 角丸 (border-radius): `12px`
  * 境界線: なし、または `1px solid [Border Color]`
  * 影 (box-shadow): `none`（フラットで上品な印象を優先）
  * 価格表記: `Primary Color` の太字で強調
* **特長タグ（ラベル）:**
  * 背景: `Primary` (`#E2592C`)、文字色 `#FFFFFF`
  * 形状: 短冊型の小さい矩形バッジ、見出しの脇に添える
* **テーブル・情報リスト（店舗情報など）:**
  * 各行を `1px solid [Border Color]` で区切る
  * ラベル列とコンテンツ列を左右に分割配置
* **背景装飾:**
  * セクション下部に山並みのグラデーションイラスト（`Secondary` 〜 `Background` のグラデーション）を配置し、奥行きと季節感を演出
  * 全体に薄い和紙・古紙風テクスチャ（ノイズ／グレイン）を重ねる
* **ヘッダー（モバイル固定バー）:**
  * 画面上部固定、高さ 56px程度、左右2分割
  * 左ブロック: `Surface`（白）背景、ハンバーガーアイコン＋「メニュー」
  * 右ブロック: `Primary` 背景、カトラリーアイコン＋「ご予約」、白文字
  * 角丸なし、影なし（フラットに画面上端へ密着）

## 6. レスポンシブ振る舞い (Responsive)
* 参考サイトはデスクトップでは右サイドナビゲーション、モバイルでは上部固定ヘッダーへと構成が明確に切り替わるため、**デスクトップファースト**で設計しつつ、モバイル用のヘッダー・装飾テキストは専用パターンとして定義する。
* **ブレイクポイント:**
  * スマホ (Mobile): `~ 767px`
  * タブレット (Tablet): `768px ~ 1023px`
  * デスクトップ (Desktop): `1024px ~`
* **モバイルヘッダー（固定・2分割バー）:**
  * 画面上部に `sticky`/`fixed` で固定される、左右2分割のヘッダーバーを採用する
  * 左側: `Surface`（白背景）+ ハンバーガーアイコン + 「メニュー」ラベル（ダークテキスト）
  * 右側: `Primary`（`#E2592C`）背景 + カトラリーアイコン + 「ご予約」ラベル（白テキスト）
  * デスクトップ版の右端縦タブ（予約ボタン）は、モバイルではこの右側ブロックに統合される
  * ロゴは左上に別途固定表示し、ヘッダーバーとは独立させる
* **縦書き・大型装飾テキストの扱い:**
  * デスクトップの `writing-mode: vertical-rl` によるサイドラベルはハンバーガーメニュー内、または非表示に統合する
  * 背景に敷く大型の装飾文字（例:「YORO UMAIMON」「美/養/味/老」等のブランドワード）は、回転させたまま縮小するのではなく、**1文字（1単語）ずつ通常の横書き方向で大きく積み上げて縦に並べる**方式に変更し、視認性を保ったまま世界観を継続させる
* **ヒーロー画像（円形トリミング）:**
  * 画面幅に応じて円の直径を縮小しつつ中央配置を維持し、背景の装飾テキストと重ねて配置する
* **情報テーブル（店舗情報・電話番号など）:**
  * デスクトップと同様、ラベル列とコンテンツ列を左右に並べた2カラム表示を維持する（スタック化しない）
  * 行の区切り線 (`Border` 色) はモバイルでも維持
* **特長タグ付き見出し（例:「特長 壱」）:**
  * タグは見出しの右側に添える横並びレイアウトを維持し、縦積みにはしない
* **カード型メニュー一覧:**
  * 1カラム表示に変更し、画像はカード上部いっぱい（幅100%）、角丸は上2角のみ、価格・説明文はその下に縦積み
* **フッター:**
  * `Primary` 背景の全幅ブロックとし、リンク項目は縦に積み上げて表示する

## 7. アクセシビリティ (Accessibility)
* すべてのテキスト（特に価格・注意書き・エラーメッセージ）は、背景色とのコントラスト比を `4.5:1` 以上にすること。特に `Background` (`#F1E4CE`) 上の `Text Muted` (`#9C9187`) は視認性が低くなりやすいため、本文には使用せずキャプション用途に限定する。
* 画像には必ず `alt` 属性を記述すること。
* 縦書きテキストを含むナビゲーションは、スクリーンリーダー利用時の読み上げ順序に配慮し、視覚的な配置順とDOM順序を一致させること。

## 8. エージェントプロンプトガイド (Agent Prompt)
AIエージェントへの指示です。コードを生成する際は、以下のルールを遵守してください。
1. 上記のトークン（変数名またはカラーコード）をハードコードせず、可能な限りCSS変数またはTailwindのクラスを用いて表現してください。
2. 明朝体（serif）を基調とし、ゴシック体（sans-serif）は極力使用しないこと。和文の品格・老舗感を損なわないようにする。
3. 日本語が不自然にならないよう、文字間隔（`letter-spacing`）や行間（特に縦書き時）を適切に調整してください。
4. 写真・食材が主役となるレイアウトを心がけ、テキストや装飾で写真の視認性を妨げないこと。
5. 未知のデザイン要素を生成する場合は、事前にユーザーに質問するか、このデザインシステムに準拠した形で提案してください。
