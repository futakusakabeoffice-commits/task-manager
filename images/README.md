# 画像の差し込み方

このフォルダに、下表のファイル名で写真（JPEG/PNG 推奨）を置くだけで、対応するページのプレースホルダー枠（グレーの斜線パターン）が自動的にその写真に置き換わります。ファイルが無い場合は、これまで通りプレースホルダー表示のままになります（HTML 側の修正は不要）。

写真は `object-fit: cover` で枠いっぱいに切り抜き表示されます。「向き」の目安に合わせたトリミングで撮影・用意すると、レイアウト崩れが起きにくくなります。

## アクセス地図について

HOME（`index.html` の `#access`）と店舗情報（`shop.html` の `.access-map`）の地図は、静止画ではなく Google Maps のインタラクティブな埋め込み（`<iframe>`）です。API キー不要の URL 形式（`https://www.google.com/maps?q=<検索キーワード>&output=embed`）を使っています。

現在は架空の地点（東京駅）を仮設定しています。実際の住所が決まったら、両ファイルの `iframe` の `src` 内、`q=` の後ろの値を実際の住所や店名（URLエンコード済み）に差し替えてください。例:

```html
<iframe src="https://www.google.com/maps?q=東京都千代田区丸の内1-1&output=embed" ...></iframe>
```

（ブラウザに直接貼り付ければ自動的に URL エンコードされます。手動で編集する場合は日本語部分を URL エンコードしてください。）

## 注意事項

- ファイル名・拡張子は上表の通りに合わせてください（`.jpg` 表記ですが `.jpeg` / `.png` / `.webp` に差し替える場合は、対応する HTML の `<img src="...">` の拡張子も変更してください）。
- 各画像の `alt` テキストは `docs/CONTENTS.md` の想定内容を踏襲済みです。撮影内容が変わる場合は `docs/CONTENTS.md` と HTML 側の `alt` / `aria-label` も合わせて更新してください。
- 画像を追加しても本文キャプション（グレー枠内の説明文）は非表示にはなりません（写真が枠を覆って自動的に隠れます）。万一写真が透過PNGなどで下地が透けるとキャプション文字が透けて見えるため、背景のある写真を使用してください。
